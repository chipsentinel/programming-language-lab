# Instalación del entorno para JavaScript

Equivalente de la lección 02 del curso de C# (instalación de Visual Studio): preparar las herramientas para programar en JavaScript.

## Herramientas

| Herramienta | Para qué sirve |
|---|---|
| **Node.js** | Entorno para ejecutar JavaScript fuera del navegador |
| **npm** | Gestor de paquetes, incluido con Node.js |
| **Visual Studio Code** | Editor de código |

## Pasos

1. Instalar [Node.js](https://nodejs.org/es) (se recomienda la versión LTS). Incluye npm.
2. Comprobar la instalación:

```bash
node --version
npm --version
```

3. Instalar [Visual Studio Code](https://code.visualstudio.com/).
4. Abrir la carpeta `javascript/` en VS Code y ejecutar un archivo desde su terminal integrada:

```bash
node archivo.js
```

No se necesitan extensiones obligatorias; VS Code ya incluye soporte para JavaScript.
