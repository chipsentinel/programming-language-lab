# Introducción a JavaScript

## Qué es JavaScript

JavaScript es un lenguaje de programación de alto nivel, interpretado y de tipado dinámico. Lo creó Brendan Eich en Netscape en 1995 para dar interactividad a las páginas web.

Su especificación es el estándar **ECMAScript**, y todos los navegadores lo ejecutan. Con **Node.js** también se ejecuta fuera del navegador, por ejemplo en servidores y herramientas de línea de comandos.

## Para qué se usa

- Interactividad en páginas web (DOM).
- Aplicaciones y APIs en el servidor (Node.js).
- Herramientas de desarrollo y automatización.
- Aplicaciones de escritorio y móviles con frameworks específicos.

## Herramientas en este repositorio

- **Node.js:** entorno de ejecución.
- **npm:** gestor de paquetes, con un proyecto por módulo.
- **Visual Studio Code:** editor.

## Qué veremos

Los mismos ocho módulos del curso de C#, adaptados a JavaScript. Las lecciones sin equivalente directo usan alternativas propias, como `map()`, `filter()` y `reduce()` en lugar de LINQ, o HTML, CSS y DOM en lugar de WPF.

## Curiosidades

- Se creó en unos diez días y sus nombres iniciales fueron *Mocha* y *LiveScript*.
- No tiene relación con Java: el nombre fue una decisión de marketing.
- Es de tipado dinámico: el tipo de una variable se decide al ejecutar, no al compilar.

## Cómo se estudia en este repositorio

Cada concepto se implementa en JavaScript después de resolverlo en C# y en Java, para comparar las soluciones.
