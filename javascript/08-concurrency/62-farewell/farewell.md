# Despedida del curso (versión JavaScript)

## Lo recorrido

El curso original (en C#) empezó **desde cero** y avanzó hasta un nivel **intermedio**, con algunos temas de nivel **avanzado**. Cada lección se ha replicado aquí en **JavaScript** para comparar las soluciones.

| Módulo | Contenido |
|---|---|
| 01 | Introducción, instalación y primer proyecto |
| 02 | Variables, tipos de datos, operadores y entrada de datos |
| 03 | Condicionales y bucles |
| 04 | Clases Math y String, arrays |
| 05 | Clases, métodos, constructores, listas y mapas |
| 06 | Programación orientada a objetos, fechas, excepciones, archivos, enumeraciones, depuración y más |
| 07 | Interfaces gráficas (DOM) y bases de datos (MySQL, Oracle y SQL Server) |
| 08 | Hilos y programación asíncrona |

En el módulo 07 las bases de datos se han tratado con **Node.js** y sus controladores (`mysql2`, `oracledb`, `mssql`); en el 08, los hilos con `Worker` y lo asíncrono con `Promise` y `async`/`await`.

## Siguientes pasos

Los caminos que propone el curso para C# tienen su equivalente en JavaScript:

| Camino en C# | Equivalente en JavaScript |
|---|---|
| ASP.NET Core, APIs REST, Blazor | **Node.js** con Express, APIs REST; **React**, **Vue** o **Angular** |
| .NET MAUI, Xamarin | **React Native** |
| Azure, microservicios con Docker | Despliegue en la nube y microservicios con Node.js y **Docker** |

## Consejos finales

- **No dejar lagunas** en el conocimiento: consolidar lo aprendido antes de pasar a lo siguiente.
- La clave es la **constancia** y la **disciplina**.
