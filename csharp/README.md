# C#

Lenguaje principal del laboratorio. Cada concepto se estudia e implementa primero aquí.

## Herramientas

- .NET SDK y .NET CLI
- NuGet para dependencias
- Visual Studio Code

## Organización

Un proyecto .NET independiente por ejercicio práctico, dentro de la carpeta del ejercicio.

```text
csharp/
└── 02-fundamentals/
    └── 05-variables/
        ├── Program.cs
        └── Exercise.csproj
```

## Comandos básicos

```bash
dotnet new console -n Exercise -o 05-variables   # crear
cd 05-variables
dotnet run                                       # ejecutar
dotnet build                                     # compilar
```
