# Despedida del curso de C#

## Lo recorrido

El curso empezó **desde cero** y avanzó hasta un nivel **intermedio**, con algunos temas de nivel **avanzado**.

| Módulo | Contenido |
|---|---|
| 01 | Introducción, instalación y primer proyecto |
| 02 | Variables, tipos de datos, operadores y entrada de datos |
| 03 | Condicionales y bucles |
| 04 | Clases Math y String, arrays |
| 05 | Clases, métodos, constructores, listas y mapas |
| 06 | Programación orientada a objetos, fechas, excepciones, archivos, enumeraciones, depuración y más |
| 07 | Interfaces gráficas (WPF) y bases de datos (MySQL, Oracle y SQL Server) |
| 08 | Hilos y programación asíncrona |

Aprender C# no es solo aprender el lenguaje: es entender **cómo construir soluciones sólidas, limpias y escalables**. C# es uno de los lenguajes más potentes del ecosistema **.NET**.

## Siguientes pasos

Con lo aprendido se puede seguir formándose en:

| Camino | Tecnologías |
|---|---|
| **Desarrollo web** | ASP.NET Core MVC, APIs REST, **Blazor** (aplicaciones interactivas) |
| **Escritorio y móvil** | **.NET MAUI** (y Xamarin, para proyectos con versiones anteriores de .NET) |
| **Nube y microservicios** | Despliegue en **Azure** (App Service, Cosmos DB), microservicios con .NET y **Docker** |

## Consejos finales

- **No dejar lagunas** en el conocimiento: consolidar lo aprendido antes de pasar a lo siguiente.
- La clave es la **constancia** y la **disciplina**.
