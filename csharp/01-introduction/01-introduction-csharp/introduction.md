# Introducción a C#

## Qué es C#

C# (se pronuncia «C sharp») es un lenguaje de programación moderno, orientado a objetos y de tipado estático, desarrollado por Microsoft. Lo diseñó Anders Hejlsberg y se publicó en 2002 junto con la plataforma .NET.

Hoy se ejecuta sobre **.NET**, una plataforma multiplataforma (Windows, Linux y macOS) y de código abierto.

## Para qué se usa

- Aplicaciones de escritorio (WPF, Windows Forms).
- Aplicaciones y APIs web (ASP.NET Core, Blazor).
- Videojuegos (Unity).
- Aplicaciones móviles y multiplataforma (.NET MAUI).
- Herramientas de consola y automatización.

## Curiosidades

- El nombre hace referencia a la nota musical *do sostenido* (♯), una idea de «C mejorado».
- Su sintaxis recuerda a la de C, C++ y Java, por lo que resulta familiar si conoces alguno de ellos.
- Es un lenguaje de tipado estático: los errores de tipos se detectan al compilar, no al ejecutar.
- Evoluciona con una versión nueva cada año, junto con .NET.
