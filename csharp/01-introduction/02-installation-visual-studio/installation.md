# Instalación del entorno para C#

## Herramientas

| Herramienta | Para qué sirve |
|---|---|
| **SDK de .NET** | Compilador y herramienta `dotnet` |
| **Visual Studio Code** | Editor de código |
| **C# Dev Kit** | Extensión de VS Code para C# |

## Pasos

1. Instalar el [SDK de .NET](https://dotnet.microsoft.com/es-es/download).
2. Instalar [Visual Studio Code](https://code.visualstudio.com/).
3. Instalar la extensión **C# Dev Kit** desde el panel de extensiones de VS Code.
4. Comprobar la instalación:

```bash
dotnet --version
```

La creación y ejecución de proyectos se explica en [`csharp/README.md`](../../README.md).

## Nota sobre el curso

El vídeo del curso instala **Visual Studio 2022** (edición Community, gratuita). En este repositorio se trabaja con VS Code y .NET CLI, por lo que esa instalación no es necesaria. Visual Studio se puede usar más adelante, por ejemplo para el diseñador visual de WPF (módulo 07), que solo funciona en Windows.
