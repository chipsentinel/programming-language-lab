# Progreso

Seguimiento del aprendizaje de las 62 lecciones del curso de referencia, por lenguaje.

C# es el lenguaje principal. Java y JavaScript se completan después, replicando cada ejercicio.

**Estados:** ⬜ Pendiente · 🟡 En desarrollo · ✅ Completado · 🔵 No aplicable.

Los conceptos siguen los títulos del curso de C#. En Java y JavaScript se usa la tecnología equivalente (por ejemplo, LINQ → Streams o `map()`/`filter()`).

Un ejercicio solo se marca como ✅ cuando está implementado en el repositorio.
