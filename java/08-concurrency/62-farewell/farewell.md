# Despedida del curso (versión Java)

## Lo recorrido

El curso original (en C#) empezó **desde cero** y avanzó hasta un nivel **intermedio**, con algunos temas de nivel **avanzado**. Cada lección se ha replicado aquí en **Java** para comparar las soluciones.

| Módulo | Contenido |
|---|---|
| 01 | Introducción, instalación y primer proyecto |
| 02 | Variables, tipos de datos, operadores y entrada de datos |
| 03 | Condicionales y bucles |
| 04 | Clases Math y String, arrays |
| 05 | Clases, métodos, constructores, listas y mapas |
| 06 | Programación orientada a objetos, fechas, excepciones, archivos, enumeraciones, depuración y más |
| 07 | Interfaces gráficas (JavaFX) y bases de datos (MySQL, Oracle y SQL Server) |
| 08 | Hilos y programación asíncrona |

En el módulo 07 las bases de datos se han tratado con **JDBC**; en el 08, los hilos con `Thread` y lo asíncrono con `CompletableFuture`.

## Siguientes pasos

Los caminos que propone el curso para C# tienen su equivalente en Java:

| Camino en C# | Equivalente en Java |
|---|---|
| ASP.NET Core, APIs REST, Blazor | **Spring Boot**, APIs REST |
| .NET MAUI, Xamarin | **Android** (Kotlin/Java) |
| Azure, microservicios con Docker | Despliegue en la nube y microservicios con Spring y **Docker** |

## Consejos finales

- **No dejar lagunas** en el conocimiento: consolidar lo aprendido antes de pasar a lo siguiente.
- La clave es la **constancia** y la **disciplina**.
