# Introducción a Java

## Qué es Java

Java es un lenguaje de programación orientado a objetos y de tipado estático. Lo creó James Gosling en Sun Microsystems y se presentó en 1995. Hoy lo mantiene Oracle.

El código fuente se compila a *bytecode*, que ejecuta la **JVM** (máquina virtual de Java). Gracias a ello, el mismo programa funciona en cualquier sistema con una JVM: es la idea de *«escribe una vez, ejecuta en cualquier lugar»*.

## Para qué se usa

- Aplicaciones empresariales y servicios backend (Spring).
- Aplicaciones Android.
- Aplicaciones de escritorio (JavaFX).
- Big data y sistemas distribuidos.

## Herramientas en este repositorio

- **JDK:** compilador y herramientas de desarrollo.
- **Maven:** compilación y gestión de dependencias, con un proyecto por módulo.
- **IntelliJ IDEA:** entorno de desarrollo.

## Qué veremos

Los mismos ocho módulos del curso de C#, con las tecnologías equivalentes de Java (por ejemplo, Streams en lugar de LINQ, JavaFX en lugar de WPF y JDBC en lugar de ADO.NET).

## Curiosidades

- Su primer nombre fue *Oak*, y el nombre actual hace referencia al café.
- Es un lenguaje muy cercano a C# en sintaxis y conceptos, lo que facilita la comparación.
- No tiene relación con JavaScript, aunque compartan parte del nombre.

## Cómo se estudia en este repositorio

Cada concepto se implementa en Java después de resolverlo en C#, para comparar ambas soluciones.
